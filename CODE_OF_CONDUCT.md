# Code of conduct

OpenHuddle is about people building things together, so the project space should feel like a
good team to be on.

- Be kind and assume good intent. Critique code and ideas, not people.
- No harassment, insults, or discrimination of any kind, in issues, pull requests, discussions
  or anywhere the project is represented.
- Keep it on topic and help newcomers find their way.
- Don't post other people's private information, including invite links and tokens.

If someone breaks these rules, report it privately through the repository's Security tab
("Report a vulnerability") or by contacting the maintainer on GitHub (@nika110). Reports are
handled confidentially. The maintainer may remove content and block people who don't follow
this code.

This code is adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org/).
