OpenHuddle
GitHub

Multiplayer mode for AI coding agents.

You and your friends each keep your own Claude Code, Codex or Cursor. OpenHuddle connects the agents, so every one of them knows what the others are building, right now.

npx openhuddle create --hub {{HUB_URL}}

Free and open source. No account, no config files. Needs Node 20 or newer.

Start a team in three steps

  1. 1

    Create the team

    In your project folder:

    npx openhuddle create --hub {{HUB_URL}}
  2. 2

    Share the invite link

    You get a link like https://…/join/t3k9…. Send it to the people you build with.

  3. 3

    Friends join

    Each friend runs this. It downloads the project if they need it and connects their AI tools.

    npx openhuddle join <link>

Then just talk to your agent

Your agent gets new abilities. You keep typing the way you already do.

  • What is Ana working on?

    Ana is on T2, the login API, editing src/api/login.ts. Last commit 4 minutes ago.

  • Plan this from our master prompt.

    Made 6 tasks. T1, the project skeleton, comes first. I proposed T2 and T3 for you, T4 and T5 for Leo, T6 for Sam.

  • I'll take the payments task.

    T4 is yours. It waits on T1, which Ana is finishing. I'll tell you the moment it's ready.

  • From now on, let the agent assign tasks.

    Done. New tasks get assigned automatically. Anyone can still swap.

How it works

A hub holds the shared picture

Who is online, the master prompt everyone wrote and voted on, the task board, which files are taken, and a live feed of what happened.

Each agent gets plugged in

Tools for asking teammates, taking tasks and posting updates. In Claude Code, news arrives on its own before each prompt and after each edit.

Git still carries the code

OpenHuddle never stores your code. Work happens on branches and merges the way it always has; the dashed line is git.

Run your own hub

The hub is the same package. Start it anywhere with Node 22.13 or newer, then point your team at it with --hub.

npx openhuddle hub
