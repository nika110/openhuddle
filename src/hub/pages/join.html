vibecrew

You’re invited to a vibecrew crew

Run this in a terminal, inside the project folder. If you don’t have the project yet, any folder works.

npx vibecrew join {{INVITE_URL}}

It joins the crew, downloads the project if you need it, and connects the AI tools you have installed: Claude Code, Codex or Cursor. Then open your AI tool in the project and say “what is everyone working on?”

Needs Node 20 or newer. This link works like a key, so share it only with people you build with.
